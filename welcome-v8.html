What's new

Cleaner verified trivia, a fixed quiz header, and a few quality-of-life improvements to posting.

✓ Better verified trivia
  • Filtered out garbage questions (random letter strings, broken encoding like %20 instead of spaces, and “who said…” questions with no actual quote)
  • Cleaned the existing bank: 466 bad questions removed, nearly 1,900 more fixed automatically
  • New imports are checked the same way, so these shouldn't creep back in
📋 Quiz header fixed
  • The quiz header again shows Morning/Afternoon, the date, and your question number (e.g. 3 / 15)
  • Category and difficulty badges stay below that, on each question
📎 Paste images into posts
  • Copy an image and paste it straight into a comment (composer or reply) — no need to use Attach
  • Works alongside the existing attach button; up to 10 images per post
★ What's New button
  • Tap ★ What's New in the header any time to read this again
  • This screen shows once automatically the first time you open the app after this update
